# Pong — Classic Arcade

A simple, responsive Pong game built with HTML, CSS, and vanilla JavaScript. Play against the computer and be the first to reach seven points.

## Play

Open `index.html` in a modern browser, or publish the repository with GitHub Pages.

- **Move:** Up/Down arrow keys or **W/S**
- **Start / pause / resume:** **Space**
- **Pause:** **Escape**
- **Touch screens:** Use the on-screen up/down controls
- **Sound:** Toggle the note button in the top-right corner
- **Restart:** Use the restart button below the court

No build tools or dependencies are required. The optional sound effects use the browser's Web Audio API.
